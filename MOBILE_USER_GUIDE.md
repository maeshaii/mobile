## Getting Started

### First-Time Login

1. **Launch the App**: Open the WNY Mobile app on your device.
2. **Login Screen**: Enter your CTU ID and password.
3. **Password Change**: If this is your first time logging in, you'll be prompted to change your password for security.
4. **Dashboard**: After logging in, you'll be taken to your home feed (or OJT dashboard if you're an OJT user).

### Account Types

The app supports different account types:
- **Alumni**: Full access to all features
- **OJT (On-the-Job Training)**: Specialized dashboard and features
- **Admin**: Administrative access
- **PESO**: Public Employment Service Office access

## Navigation

The app uses a **bottom navigation bar** that's always accessible. The navigation bar includes five main sections:

### Bottom Navigation Icons

1. **Home** 🏠
   - Takes you to your main feed
   - Shows posts from people you follow
   - OJT users see a specialized OJT dashboard

2. **Search** 🔍
   - Search for alumni and OJT users
   - View recent searches
   - Access user profiles

3. **Notifications** 🔔
   - View all your notifications
   - Badge shows unread count (red number)
   - Real-time updates for likes, comments, mentions, etc.

4. **Messages** ✉️
   - Access your conversations
   - Badge shows unread messages and message requests
   - Filter by: All Messages, Message Requests, Online Users

5. **Profile** 👤
   - View your profile
   - Access settings and menu options
   - Log out

**Note**: The active tab is indicated by a white underline and bold text.

## Home Feed

The Home Feed is your main screen where you'll see posts from people you follow.

### Features

- **Pull to Refresh**: Pull down on the feed to refresh and see new posts
- **Create Post Button**: Tap "Start a post" at the top to create a new post
- **People You May Know**: Suggestions for users to follow appear in your feed
- **Post Feed**: Scroll through posts, reposts, and donation posts

### Viewing Posts

- **Tap a post** to see full details
- **Scroll** to see more posts
- Posts show:
  - Author name and profile picture
  - Post content and images
  - Like, comment, and repost counts
  - Timestamp (relative time, e.g., "2 hours ago")

## Search

The Search feature helps you find other users in the network.

### How to Search

1. Tap the **Search** icon in the bottom navigation
2. Type a name in the search bar
3. Results appear as you type
4. Tap on a user to view their profile

### Search Features

- **Recent Searches**: Your recent searches are saved and displayed
- **Clear Recent Searches**: Tap the clear button to remove all recent searches
- **User Profiles**: Tap any search result to view that user's profile and posts

## Notifications

Stay updated with all activity related to your account.

### Notification Types

- **Post Interactions**: Likes, comments, reposts on your posts
- **Mentions**: When someone mentions you in a post or comment
- **Message Requests**: New message requests from users
- **Tracker Reminders**: Reminders to update your employment tracker
- **Employment Updates**: Reminders to update your employment status
- **Rewards**: Notifications about rewards and points
- **Admin/PESO Notifications**: Important announcements

### Using Notifications

1. **View Notifications**: Tap the bell icon (red badge shows unread count)
2. **Mark as Read**: Tap a notification to mark it as read
3. **Delete Notifications**: Swipe left on a notification to delete it
4. **Select Multiple**: Tap the selection icon to select and delete multiple notifications
5. **Navigate to Content**: Tap a notification to go to the related post, comment, or message

### Notification Badges

- Red badge with number = unread notifications
- Badge disappears when all notifications are read

## Messages

Communicate with other users through direct messaging.

### Message Features

- **Real-time Messaging**: Messages appear instantly
- **Typing Indicators**: See when someone is typing
- **Online Status**: See who's currently online
- **Message Requests**: Accept or decline message requests
- **File Attachments**: Send images, videos, documents, and audio files
- **Message Actions**: React, reply, edit, and delete messages

### Using Messages

#### Viewing Conversations

1. Tap the **Messages** icon in the bottom navigation
2. See all your conversations listed
3. Red badge shows unread message count and message requests
4. Filter conversations:
   - **All Messages**: All conversations
   - **Message Request**: Pending requests
   - **Online**: Users currently online

#### Starting a Conversation

1. Go to a user's profile
2. Tap the message button
3. Or search for a user and start messaging

#### Sending Messages

1. **Text Messages**: Type in the input field and tap send
2. **Attach Files**: 
   - Tap the attachment icon (📎)
   - Choose from:
     - **Camera**: Take a photo
     - **Photo Library**: Select existing photos
     - **Document**: Select documents (PDF, Word, etc.)
   - Multiple images can be attached
3. **Send**: Tap the send button

#### Message Actions

- **React to Messages**: Long-press a message to add emoji reactions
- **Reply to Messages**: Long-press and select "Reply" to reply to a specific message
- **Edit Messages**: Long-press your own message and select "Edit"
- **Delete Messages**: Long-press and select "Delete"
- **View Reactions**: Tap on reaction emojis to see who reacted

#### Viewing Attachments

- **Images**: Tap to view full screen, pinch to zoom
- **Videos**: Tap to play, full-screen playback available
- **Documents**: Tap to download or view
- **Download**: Long-press attachments to download to your device

#### Message Requests

- **Accept**: Tap "Accept" to start a conversation
- **Decline**: Tap "Decline" to reject the request
- **View Profile**: Tap the user's name to view their profile before accepting

## Creating Posts

Share your thoughts, updates, and media with the community.

### Creating a New Post

1. Tap **"Start a post"** at the top of your home feed
2. Or navigate to the Posts section from your profile

### Post Creation Options

- **Regular Post**: Standard text and image post
- **Forum Post**: Post in a forum discussion
- **Donation Post**: Create a donation campaign

### Adding Content

1. **Text**: Type your message in the text field
2. **Images**: 
   - Tap the image icon
   - Choose from camera or photo library
   - Select multiple images (up to the limit)
   - Images can be removed before posting
3. **Preview**: Review your post before publishing
4. **Post**: Tap the post button to publish

### Editing Posts

1. Go to your post
2. Tap the three dots menu (⋯)
3. Select "Edit"
4. Make your changes
5. Save the updated post

**Note**: Edited posts show an "Edited" indicator.

## Interacting with Posts

Engage with posts through various interactions.

### Post Actions

1. **Like** ❤️
   - Tap the heart icon to like a post
   - Tap again to unlike
   - See who liked by tapping the like count

2. **Comment** 💬
   - Tap the comment icon
   - Type your comment
   - Mention users with @username
   - Post your comment

3. **Repost** 🔄
   - Tap the repost icon
   - Add an optional caption
   - Share the post to your feed

4. **View Details**
   - Tap on a post to see:
     - Full post content
     - All comments
     - Who liked it
     - Who reposted it

### Viewing Post Interactions

- **Likes**: Tap the like count to see all users who liked
- **Comments**: View all comments on the post
- **Reposts**: See who reposted the post

### Post Options Menu

Tap the three dots (⋯) on a post to:
- **Edit** (your own posts only)
- **Delete** (your own posts only)
- **View Post Details**

## Tips & Troubleshooting

### General Tips

1. **Pull to Refresh**: Most screens support pull-to-refresh to update content
2. **Badge Notifications**: Red badges show unread counts - tap to view
3. **Long-Press**: Many items support long-press for additional options
4. **Swipe Actions**: Swipe left on notifications and messages for quick actions

### Common Issues

#### Messages Not Loading
- Check your internet connection
- Pull down to refresh
- Try logging out and back in

#### Notifications Not Appearing
- Check notification permissions in device settings
- Ensure you're logged in
- Pull to refresh the notifications screen

#### Images Not Uploading
- Check file size (large files may take time)
- Ensure you have internet connection
- Try selecting a different image

#### Can't Send Messages
- Verify you've accepted the message request (if applicable)
- Check your internet connection
- Ensure the recipient hasn't blocked you

#### App Crashes or Freezes
- Close and reopen the app
- Clear app cache (device settings)
- Update to the latest version
- Restart your device

### Getting Help

- **Contact Support**: Use the settings menu to contact support
- **Report Issues**: Report bugs through the app feedback feature
- **Check Updates**: Keep the app updated for the latest features and fixes
